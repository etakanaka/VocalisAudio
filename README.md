# VocalisAudio
Vocalis Audio is an open-source, AI-assisted suite of native Linux VST3 plugins for REAPER. Built for podcasters, video creators, streamers, and spoken-word producers, it offers practical tools for cleaner recordings, clearer vocals, balanced audio levels, and accurate loudness control.

## Our Philosophy — Audio That Just Works

**“It does its job, and it's still there when you open your project tomorrow.”**

Vocalis Audio is built around a simple idea: **Linux creators shouldn't have to sacrifice workflow reliability just to process a voice.**

Linux has an incredible audio ecosystem, but working with certain plugins can mean relying on compatibility layers, bridging software, additional dependencies and workarounds. These solutions can be useful, but they also introduce uncertainty, particularly when upgrading a system, moving between distributions or reopening older projects.

We believe audio production should be simpler than that.

Vocalis focuses on native, open-source audio tools that perform specific tasks without unnecessary complexity. Our goal isn't to recreate every feature of expensive commercial plugins or claim to outperform them. It's to provide practical tools that work consistently, integrate naturally into Linux workflows and remain dependable over time.

We're building Vocalis around a few straightforward principles:

- **Native by design.** Linux VST3 plugins without Wine, Windows plugin bridges or compatibility wrappers.
- **Focused functionality.** Each plugin should solve a clearly defined audio problem without unnecessary complexity.
- **Predictable processing.** Audio should remain transparent and controllable, without unexpected changes or unwanted artifacts.
- **Project continuity.** Plugin updates should preserve existing sessions, presets, parameters and automation wherever possible.
- **Fewer dependencies.** Keep installation straightforward and minimise external requirements that could complicate moving between Linux systems.
- **Open development.** Source code should be available for inspection, improvement and community contributions.

Vocalis is still an evolving project. These principles are engineering goals, not claims that every release has already achieved them. We intend to test, document limitations, fix problems and improve compatibility as the toolkit develops.

Ultimately, Vocalis isn't about making the most complicated audio software. It's about making useful tools that Linux podcasters, video producers, streamers and other creators can rely on.

**Because the best plugin isn't always the one that does the most. Sometimes, it's the one that does what you need and keeps doing it.**
