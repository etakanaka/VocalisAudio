# Voice current limitations and acceptance gaps

Approved GUI size is 960 x 617, with fixed-ratio resizing and Settings choices at 840 x 540 and 1200 x 771. The size path is covered by compiled offscreen tests. The native GUI and REAPER host checks listed below remain unverified; no manual REAPER compatibility claim is made.

No known critical/high defect remains from this audit's reproduced cases. This is a scope-limited finding, not proof of universal correctness.

* **BLOCKED — installation:** ~/.vst3 is read-only in this execution session. The installer identifies the existing unmarked Voice bundle correctly but cannot create a staging directory. Run scripts/install.sh in a normal terminal. Staged install, backups, uninstall, protection and binary hashes pass. No installed plugin was changed.
* **UNVERIFIED — REAPER:** discovery, native editor embedding, real knob/mouse input, meters in a live session, automation envelopes, session saving/reopening, offline rendering, hard host bypass and multiple-instance DAW performance still require the supplied temporary-session procedure. A JUCE VST3 harness is not REAPER certification.
* **UNVERIFIED — native GUI interaction:** XOpenDisplay fails. Compiled offscreen rendering, bindings, callbacks, keyboard adjustment and lifecycle tests pass, but physical pointer dragging, focus, hover on a desktop, text typing, native popup dismissal and native scaling cannot be claimed. An initial TextEditor-opening test crashed due to unavailable native display; Label parsing is tested instead and native typing is explicitly pending.
* **BLOCKED — ThreadSanitizer:** even a minimal atomic/thread runtime probe fails with unexpected memory mapping (66). Concurrent callback/APVTS/meter stress passes, but does not establish race freedom.
* **BLOCKED — LeakSanitizer:** a minimal threaded ASan/LSan probe reports fatal ptrace restrictions. ASan/UBSan and repeated editor cycles with concurrent audio pass with leak detection disabled. No leak-free claim is made.
* **UNVERIFIED — human recordings and listening:** no recorded speech/singing corpus was supplied. Synthetic syllabic, harmonic, noisy, transient, silent and quiet inputs pass numerical tests. Subjective naturalness, sibilance, ringing/metallic coloration and mix suitability still require audition.
* **Design adaptations:** Voice's control placement/canvas differs intentionally. Stereo pairs reuse Rider's single-channel meter; GR changes range/direction while retaining meter materials. Semantic red clipping/sensitivity is additional because Rider has no equivalent. Rider has no settings icon; the existing standard button renderer is used for Settings. Voice retains its original meter ballistics rather than importing Rider's different detector time constants. Full native two-plugin screenshot comparison is unavailable; existing Rider render and actual compiled Voice render were inspected, and 30 shared-renderer pixel comparisons pass.
* **Existing intentional DSP constraints:** no limiter, de-esser, noise reduction, pitch correction or tempo sync. Clipping remains possible. Harmonics are deliberately very subtle and not oversampled; no alias-free claim. Disabled effects keep running and fade the complete return, including tails. No automatic makeup gain. UI scale remains per-editor; DSP histories reset on prepare/reload and are not serialized.
* **State:** malformed/partial version-1 parameter states are now rejected as a whole. Valid old states remain supported. No schema or host parameter identity changed. Parameter writes are independent atomics with smoothing, not a multi-parameter transactional snapshot.

Use VOICE_FINAL_AUDIT.md for findings/severity and VOICE_REGRESSION_TESTS.md for exact executed evidence. Controlled testing remains the release status.
